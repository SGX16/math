## 核心结论

- **模型**：径向一维热传导–水分扩散耦合 PDE；问题 4 用物质坐标 $\xi=r/R(t)$ 处理移动边界。
- **验证**：与无限长圆柱解析解对比，热误差 $4.2\times10^{-3}$ °C、质误差 $9.9\times10^{-5}$ kg/kg。
- **物理规律**：干燥过程**由传质控制**（热扩散系数约为水分扩散系数的 24 倍），烘干时长对 $h_m$ 高度敏感、对 $h$ 几乎不敏感。
- **收缩效应**：半径收缩使 $R^2$ 减小，烘干时长缩短约 50%（附录 4 无收缩 39.2 h → 有收缩 19.7 h）。

## 运行环境与复现

Python 3.11 + `numpy scipy openpyxl matplotlib`（`py -m pip install numpy scipy openpyxl matplotlib`）。

```bash
cd solution
py main.py          # 求解并生成 result1~4.xlsx
py verify.py        # 解析解验证
py analysis.py      # 收敛性与灵敏度
py make_figures.py  # 生成图表
```

> 附件路径在 `main.py` 顶部 `DATA` 变量中配置，默认指向 `../附件`。
